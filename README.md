# 🎮 PacMan Game – Java

A classic **Pac-Man Game** developed using **Java**. This project recreates the traditional arcade gaming experience where players control Pac-Man, navigate through a maze, collect points, and avoid enemies.

The project is designed to practice Java programming concepts, game logic, and object-oriented programming.

## 🚀 Features

- 🎮 Classic Pac-Man gameplay
- 🟡 Maze-based game environment
- 👻 Enemy and ghost interactions
- 🍒 Collectibles and scoring system
- ⌨️ Keyboard-based player controls
- 🏆 Game-winning and losing conditions
- 🎨 Graphical game interface

## 🛠️ Technologies Used

- **Programming Language:** Java
- **IDE:** IntelliJ IDEA / Eclipse / NetBeans
- **Concepts:** Object-Oriented Programming (OOP)
- **Graphics:** Java GUI (Swing/AWT, if used in this project)

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/irajat111/PacManJava.git
   ```

2. Open the project in your preferred Java IDE.

3. Configure the JDK if required.

4. Locate the main Java class containing the `main()` method.

5. Run the application and start playing!

## 🎮 Game Controls

| Key | Action |
|---|---|
| ↑ Up Arrow | Move Up |
| ↓ Down Arrow | Move Down |
| ← Left Arrow | Move Left |
| → Right Arrow | Move Right |

*Controls may vary depending on the implemented game logic.*
